# 法律科技竞品监控周报站点更新说明

## 每周更新

1. 复制上一期文件，改成新日期文件名，例如：

   `issues/2026-08-19.html`

2. 将新的周报 HTML 内容替换到这个文件中。周报内部的截图、样式和证据链接可以继续保持内嵌，不需要拆分资源。

3. 打开 `data/issues.json`，在数组最前面增加一条记录：

   ```json
   {
     "title": "法律科技产品竞品监控周报",
     "period": "2026/08/12—2026/08/19",
     "publishedAt": "2026-08-19",
     "file": "issues/2026-08-19.html",
     "tags": ["竞品", "行业政策", "法律科技论文", "测评与技术文章"],
     "summary": "用一两句话概括本期重点。"
   }
   ```

4. 首页会自动按照 `publishedAt` 倒序显示最新一期和往期列表，不需要修改 `index.html`。

## 本地预览

在 `weekly-report-site` 目录启动静态服务：

```bash
python3 -m http.server 8001 --bind 127.0.0.1
```

然后打开：

`http://localhost:8001/`

## 给其他人访问

`localhost` 只对当前电脑可见。若要让其他人通过固定网址访问，需要把整个 `weekly-report-site` 目录部署到静态网站托管服务，例如公司服务器、GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。

部署时使用 `weekly-report-site` 作为网站根目录，入口文件是 `index.html`。以后每周更新 `issues/` 和 `data/issues.json` 后重新发布即可。
