01

核心摘要

结论先行

一句话总结

法律 AI 正从单点工具进入“专业数据 + Skill / MCP + Agent 工作空间”的组合竞争，产品价值越来越取决于证据回源、连续执行和结果进入后续业务流程的能力。

最重要的竞品动作

北大法宝推出法规文件智能审查，幂律智能更新 MeWork，iCourt 上线庭审证据 Skill，得理与法天使分别通过 MCP 进入通用 Agent 平台。

最大风险或威胁

专业内容平台正把数据库封装成知识图谱和 MCP；通用 Agent 同时补齐应用生成与多工具协作，可能压缩单点法律工具的入口价值。

建议关注的机会

优先建设可复用法律 Skill、专业数据连接和合同审查公开评测体系，并用引用核验、版本控制和人工复核构成可信交付闭环。

可能的用户需求变化

对我方的判断
应将来源定位、权限继承、版本有效性和引用核验做成底层能力，并考虑以 MCP / API 输出专业能力。

评测信号
