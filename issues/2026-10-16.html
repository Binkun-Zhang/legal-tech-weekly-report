01

核心摘要

结论先行

一句话总结

本周法律 AI 的竞争焦点从单点功能转向可复用 Skills、持续案件工作空间、法务受理入口和多 Agent 工作编排。

最重要的竞品动作

MeWork 同周补齐法律 Skills 与长期项目协作；智谱发布 GLM-Legal；Harvey 与 Legora 分别推出 Intake，Harvey进一步上线事项级工作编排。

最大风险或威胁

Microsoft 将20多项法律技能直接放进 Word，通用办公平台正在把法律能力、文件入口和跨应用 Agent 工作流合并为统一产品。

建议关注的机会

围绕项目记忆、证据回源、可审计工具调用和单位任务成本建立统一评测，并把高频法律方法封装为可复用 Skill。

主题洞察一：法律 AI 进入“可复用技能 + 持续事项工作区”阶段

观察到的共性动作
MeWork 同周扩展法律 Skills 与项目工作台；Harvey 推出 Intake 和事项级编排；Legora 也以 Intake、Skills 和集成生态承接企业法务请求。
可能的用户需求变化
用户不再满足于单轮问答，而是要求 AI 记住案件资料、复用专业方法、接收持续请求，并在每个审核节点保留人工控制。
对我方的判断
优先建设事项级共享上下文、可复用 Skill、成果回存和审核节点，把检索、证据、文书与项目管理放入同一工作空间。

主题洞察二：办公入口竞争加剧，可靠性与成本治理成为防守线

竞争信号
Microsoft 把20多项法律技能直接放进 Word，WorkBuddy 引入更强 Agent 模型，MCP 与连接器持续把法律数据带入通用办公平台。
技术与风险信号
OpenTelemetry、测试 harness、幻觉检查和 Cost per Task 同时升温，说明采购方需要的不只是功能，而是可追踪、可核验、可计量的执行过程。
建议结论
建立统一任务基准，持续记录引用正确率、失败类型、人工接管率、调用轨迹与单位任务成本，并将这些指标纳入产品默认治理能力。
