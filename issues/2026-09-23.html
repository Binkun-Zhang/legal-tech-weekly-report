01

核心摘要

结论先行

一句话总结

本周法律 AI 竞争聚焦入口与数据层：OpenAI 发布 Astra for Law，北大法宝发布法宝灵境，法律能力经 MCP 与技能包批量接入通用平台。

最重要的竞品动作

北大法宝发布法宝灵境并升级律爱多，幂律智能发布 MeWork v0.3.16 强化合同审查，OpenAI 推出自带法律检索索引的 Astra for Law。

最大风险或威胁

ChatGPT 企业版、WorkBuddy 与千问等通用平台正成为法律能力分发入口，法律产品若不被集成将面临入口边缘化。

建议关注的机会

把审查标准封装为可分发的技能包与 MCP 服务，同步自建权威数据层与内部评测基准，抢占「被集成」路线。

深度洞察

从“发生了什么”走向“为什么”和“怎么办”

主题洞察一：法律能力的分发入口向通用平台聚集

观察到的共性动作
汤森路透与 Definely 经 MCP 进入 ChatGPT 企业版，北大法宝 MCP 2.0 与律爱多上架 WorkBuddy，企查查 MCP 与方达技能包进入千问系。
可能的用户需求变化
用户希望在既有办公平台内直接调用法律能力，而不是切换到独立法律工具。
对我方的判断
同时准备自有入口与被集成两条路线，把技能包和 MCP 服务作为标准交付物并保留计费与留痕。

主题洞察二：数据层与实测口碑成为差异化主战场

技术信号
Astra for Law 自带 2.3 亿 URL 法律索引，Legora 构建研究基础层，Manupatra 主张模型趋同后差异化在数据层。
用户信号
合同审查软件横评按审查结论落地形态分档，能否把结论落到审批流与签署文件正成为用户选型口径。
建议结论
自建权威数据层与可核验引用，并把留痕与引用核验沉淀为产品默认能力。
